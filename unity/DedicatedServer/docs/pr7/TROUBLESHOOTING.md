# Диагностика

| Симптом | Действие |
|---|---|
| Unity CLI просит UAC | Подтвердите установщик Unity в Windows или установите **6000.6.7f1 + Linux Dedicated Server Build Support** через Unity Hub → Installs. Существующий редактор можно сохранить рядом. |
| Unity CLI пишет, что проект открыт | Закройте окна Editor для этого проекта перед batch-сборкой. |
| `SERVER_ERROR` при старте | Проверьте map, номер UDP-порта, диапазон игроков и конфликт слушателей. Для Steam проверьте game/query UDP и путь к Valve steamclient.so. |
| SSH молчит | Проверьте загрузку гостя, OpenSSH и NAT forwarding loopback:2227. |
| Docker healthy, игрок не подключается | Проверьте совместимость профиля, host/port клиента, проброс /udp в Docker и VirtualBox или туннель. Сверьте HANDSHAKE_OK на обоих концах. |
| Public UDP отсутствует при ping | Подключитесь Unity-клиентом и проверьте игру. ICMP и TCP не проверяют игровую связность UDP. |
| Steam не инициализируется | Укажите разрешённый App ID и откройте Steam под текущим пользователем. Сохраните фактический STEAM_INIT_* или SESSION_ERROR. |
| Steam logged on, список пуст | Проверьте App ID, совпадение tags, достижимость query port и адрес game server, указанный Steam backend. App ID 480 может ограничивать dedicated-публикацию. |
| Полная сессия или несовместимая сборка | Обновите список, сверьте BUILD_ID и сетевой профиль. |
| Падает Steam SDK внутри контейнера | Проверьте x86-64 архитектуру файла, наличие официальной библиотеки Valve и доступ пользователя 10001 к смонтированному файлу. |
| VM упирается в 20 GiB | Снимите `df -h /` и `docker system df`. При необходимости увеличьте диск и раздел после резервной копии. |
