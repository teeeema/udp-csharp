# План тестирования ПР7

Для каждого теста сохраните дату, версию сборки, клиентские и серверные логи и укажите фактический статус в [TEST_RESULTS.md](TEST_RESULTS.md). Для игровых сценариев используйте логи NGO и реальные скриншоты. Для Steam требуется видимость с другого устройства с собственным Steam-аккаунтом. Перед публикацией удалите только данные доступа и приватные адреса из копий доказательств.
