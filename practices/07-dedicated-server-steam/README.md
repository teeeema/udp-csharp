# ПР7. Linux Dedicated Server, Docker и Steam

Сервер DUSTLINE собран для Linux и проверен в Docker внутри Ubuntu VM. Два Windows-клиента подключились в локальной сети. Проверены движение, серверная стрельба, переподключение и восстановление контейнера после аварии.

Публичное подключение двух внешних клиентов и поиск с входом через Steam Internet-list остаются неподтверждёнными. Итог матрицы T01–T28 — **19 PASS и 9 BLOCKED**.
