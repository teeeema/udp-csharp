# ПР3. Надёжная отправка команд поверх UDP

Команда `SHOOT` подтверждается отдельным `ACK`. Клиент повторяет отправку по адаптивному тайм-ауту. Сервер распознаёт дубликаты и применяет выстрел один раз в пределах окна дедупликации.
