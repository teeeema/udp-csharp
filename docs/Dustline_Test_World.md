# DUSTLINE — открытый мир для сетевых тестов

> 23.10.2026: по запросу пользователя восстановлены исходный процедурный танк и простой песчаный полигон. Актуальные проверки и кадр: [Dustline_Restored.md](Dustline_Restored.md). Ниже сохранено историческое описание варианта с импортированными моделями.

Это свободный тестовый полигон для практики: улучшенная модель танка, пустынная площадка 500 × 500 м, открытые дороги, аванпост, ангар, вышки, грузы и низкие бетонные укрытия. Из аванпоста можно выехать в любом направлении. Задания, гонка, контрольные точки и таймер прохождения отсутствуют.

## Запуск

Готовая macOS-сборка: `unity/PredictionDemo/Builds/PR4PredictionDemo.app`.

1. Открыть приложение и нажать **START HOST / SOLO TEST** для локального теста.
2. Для сетевого теста запустить второй экземпляр и выбрать **JOIN**. На одном компьютере адрес `127.0.0.1`, порт 7777; между компьютерами использовать LAN IP хоста.
3. **WASD** — свободное движение, **Space** — рывок, **B** — намеренное расхождение клиентского предсказания, **F3** — учебная панель сети. B следует проверять на отдельном клиенте: host уже работает в авторитетном процессе.
4. В панели F3 доступны профили 0 ms / 0%, 100 ms / 0%, 175 ms / 5%, переключатель Prediction и метрики ACK/pending/reconciliation/dash. Для сравнения задержек выбирать одинаковый профиль на host и client.
5. **LEAVE SESSION** завершает локальное подключение и возвращает меню.

Открыть второй экземпляр на macOS:

```bash
open -n unity/PredictionDemo/Builds/PR4PredictionDemo.app
```

В Unity 6000.3.8f1 открыть проект `unity/PredictionDemo` и сцену `Assets/Scenes/PredictionDemo.unity`. Меню **PR4 → Build Demo Assets** пересоздаёт полигон и prefab из исходного сборщика, **PR4 → Build macOS Demo** пересобирает приложение.

## Что проверять на локации

- На прямых дорогах: движение, рывки и видимую задержку с Prediction ON/OFF.
- На низких укрытиях и грузах: остановку танка и рывка, контакт боком.
- На удалении от аванпоста: свободный выезд за прежний периметр и слежение камеры.
- В двух экземплярах: отображение второго танка, удалённое движение и reconciliation при 175 ms / 5%.

Визуальная модель заменена готовым Abrams (CC0, Sketlux/yd); добавлены готовые модели окружения и PBR-материалы. Визуальное направление следует фактическому перемещению. У импортированного танка нет готового рига, отдельная анимация гусениц и башни не добавлена. Коллизия шасси рассчитывается общим SphereCast для предсказания и сервера; декоративные детали не создают самостоятельных коллайдеров. Сетевой танк сохранён в `Assets/Prefabs/PredictedPlayer.prefab`, импортированная модель — в `Assets/ThirdParty/MilitaryRange/Abrams/`.

## Границы практических работ

Собственный UDP-протокол ПР3 находится в `src/` и проверен отдельно: [аудит](Practice3_Audit_2026-10-22.md). Unity-полигон использует прежний Netcode-проект ПР4. Он подходит для визуальных тестов prediction/reconciliation; его запуск не доказывает работу собственного ACK/retransmission из ПР3.

Для редактирования и проверки в живом Editor добавлен `com.unity.pipeline` 0.9.0-exp.1. Интерфейс использует уже установленный uGUI и штатные TMP Essential Resources с лицензией LiberationSans. Готовые модели и материалы CC0 интегрированы; платные ассеты не использованы. [Состав ассетов, лицензии и проверка сохранения логики](Visual_Upgrade_Report.md).

[Результат](test-results/dustline-sandbox-runtime.json), [воспроизводимый проверочный код](test-results/dustline-sandbox-verification.cs.txt).
