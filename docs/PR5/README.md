Условия: macOS Apple Silicon; Unity 6000.6.7f1, NGO 2.13.3, Unity Transport 6.6.0, URP 17.6.0. Localhost, два отдельных процесса одной development-сборки (Host + Client), 50 серверных сетевых объектов, по 120 секунд на режим; BASELINE и OPTIMIZED запускались последовательно с profile 0. Измерялся исходящий NGO payload Host в KB/s (1000 байт), без UDP/IP заголовков, транспортных ACK и повторов. Для комбинированного движения и стрельбы: 78.423 → 5.501 KB/s, снижение 92.985%; точные значения сохранены в данных.

## Как проверить результаты по документации

Открыть таблицу в [отчёте оптимизаций](Replication_Optimization.md) и [неокруглённый агрегат](data/traffic-summary.json). Для независимого пересчёта использовать [накопленные счётчики](data/traffic-counters.csv): выбрать mode/role и окно ServerTime из BASELINE, вычислить (последний tx − первый tx) / (последний t − первый t) / 1000. Процент снижения = (BASELINE − OPTIMIZED) / BASELINE × 100. Число игроков в каждом сравнительном окне равно двум; на сервере 50 props, у Client в OPTIMIZED число меняется по релевантности.

[Сводка тестов](data/test-summary.json): EditMode 37 PASS, PlayMode 2 PASS, .NET UDP 78 PASS; итого 117/117. Аудиторская матрица: 42 PASS, 0 FAIL, 1 BLOCKED, 5 NOT_EXECUTED. Пять обнаруженных дефектов исправлены. Полные исходные runtime-логи и тестовые протоколы сохранены локально с проектом; публикация не означает повторный запуск тестов на GitHub.

Для локальной демонстрации требуется отдельный исправленный проект Practice5Replication или ReplicationLab.app из локального архива сдачи: Host и Client, одинаковый порт (по умолчанию 7777), profile 0; OPTIMIZED включается на сервере. Эта ветка документации не является способом скачать новую игру. Буквальное выполнение Unreal API и принятие Unity преподавателем не заявляются; см. [границы адаптации](Unity_Adaptation.md).
