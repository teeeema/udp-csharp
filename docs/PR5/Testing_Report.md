## Выполненные сценарии

- Нормальное движение 4 м/с, частые/пакетные команды, duplicate/stale sequence, нечисловые значения, коррекция отклонённого движения. В native-тесте 500 реальных owner RPC: 495 отклонены, максимум 0,4 м. В 120-секундном обычном сценарии отклонений движения нет в обоих режимах.
- По три Shutdown/StartHost и четыре волны подключения в каждом режиме; по 50 объектов после запуска, без двойных callback.
- Открытая цель HP100→90; танк и стена блокируют урон; ближайшая из двух целей, дальность, неверное направление, повтор SHOOT; здоровье реплицируется удалённому клиенту.
- RX после 1/2/4 Initialize: одно контролируемое событие 10 B учитывается как 10 B. Счётчики сбрасываются с новой сессией.
- 100 реальных NetworkHide/Show в обоих режимах; 100 spawn/despawn и Despawn(false)→Spawn в PlayMode. Материалы не накапливаются, цвет через MaterialPropertyBlock сохраняется. Память наблюдалась после прогрева; конечный тест не доказывает отсутствие любых утечек за неограниченное время.
- Реальные Transport SimulatorPipelineStage: 100 мс/0% и 175 мс/5%, seed 8123; логический profile 0 исключает двойную эмуляцию. Ненулевая CSP-коррекция (до 2 м искусственного расхождения), стрельба и reconciliation подтверждены.
- Пешие выход/возврат через границу релевантности с актуальным HP70 после возвращения; динамический spawn с HP55 и удаление видны отдельному native Client.
- Около 185 секунд на режим: Host + два удалённых клиента, позднее подключение, SIGKILL одного клиента, timeout и новый клиент. Это ограниченный localhost soak.
- Финальная macOS-сборка выполнена. Архив распакован с проверкой CRC, файловых SHA-256 и прав запуска. Обычные Host/Client из распакованной .app видят двух игроков и 50 props; 7/7 проверок, оба exit code 0. Пересборка на чистой машине этим не подтверждается.

Дополнительные перекрывающиеся suites: native logical 29/29; restart event-handshake 17/17; soak 9/9; latency100 7/7; dynamic spawn 6/6; прежние log predicates 11/11. Их нельзя складывать с framework и аудиторской матрицей как независимые тесты.

## Ограничения и промежуточные попытки

BLOCKED (1): полный UDP-захват — macOS BPF permission denied; системные разрешения не менялись.

NOT_EXECUTED (5): нижнеуровневые UTP byte totals; чистая машина без package cache; принудительная перестановка wire UDP; поддельный RPC чужого владельца; WAN/многочасовая работа. Timestamp/deltaTime и произвольный target отсутствуют в клиентском RPC и не тестируются как несуществующие входные поля; серверные инварианты проверены отдельно.

Первые native-попытки дали неполные окна подключения (20/25; затем один непроверенный четвёртый reconnect). Расписание заменено ожиданием реальных сетевых событий; итоговый restart suite дал 17/17. Критерии и определения проверок не ослаблялись. Промежуточная ошибка ссылки тестовой сборки исправлена до итоговых 37/37 и 2/2; queued build повторён после domain reload. Полные протоколы успешных и неготовых попыток сохранены локально, в Git не загружаются.

Готовность к контролируемой Unity-демонстрации подтверждена для проверенного объёма. Production/WAN-гарантии и буквальное соответствие Unreal не заявляются.
